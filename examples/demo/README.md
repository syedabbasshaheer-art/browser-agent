# A demo board: Trailhead

A made-up project, a weekend-trip planner, written to show every kind of card: done with its proof, in progress,
ready, yours, waiting for an approval, blocked, and waiting on another card. The pictures in the main README are
taken from it.

To see it as a page, from the repository's folder:

```bash
COCKPIT_RECORD=examples/demo/BOARD.md node plugin/src/build/build.mjs
```

Then open `.claude/board.html` in a browser. Opened from a file, the page shows the plan; the live feed and the
buttons need the page to be published from a Claude Code session.
